# 🛵 Delivery Sales Predictor — Machine Learning em Python

Este repositório contém uma aplicação prática de **Machine Learning** estruturada em Python para prever o valor estimado de pedidos em um ecossistema de delivery com base em atributos como distância de entrega, tempo de preparo, quantidade de itens e dia da semana.

## 🚀 Tecnologias Utilizadas
- **Python 3**
- **Pandas** (Tratamento e manipulação de dados)
- **Scikit-Learn** (Construção e avaliação do modelo de Machine Learning)
- **Random Forest Regressor** (Algoritmo de previsão)

## 📊 Estrutura do Projeto
1. **Tratamento de Dados:** Organização de features preditivas e variável alvo (*target*).
2. **Divisão de Treino/Teste:** Validação cruzada para evitar *overfitting*.
3. **Treinamento & Avaliação:** Cálculo do Erro Médio Absoluto (MAE) e R².
4. **Inferência:** Previsão em tempo real de novos pedidos simulados.
